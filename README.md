# Learnex — Learning & Practice Platform

Learnex is a web-based educational platform designed to help students practice aptitude, improve verbal reasoning, and explore general knowledge through organized learning resources. It also provides pages for contests, teacher profiles, courses, and user signup.

## Features

- **Aptitude Practice:** Explore aptitude topics and problem-solving resources.
- **Verbal Reasoning:** Access content to practice verbal ability and reasoning.
- **General Knowledge:** Browse general knowledge learning materials.
- **Contests:** Dedicated page for contest-related information.
- **Teacher Profiles:** View profiles of teachers featured on the platform.
- **Courses:** Explore available learning resources and course information.
- **Signup Page:** User registration interface.
- **Multi-page Website:** Separate pages for different learning categories and sections.

## Tech Stack

- **HTML5** — Page structure and content
- **CSS3** — Styling and layouts
- **JavaScript** — Client-side interactivity

## Project Structure

The project contains separate HTML and CSS files for its main pages and sections, along with JavaScript files and image/video assets used throughout the website.

Key pages include:

- `index.html` — Main entry page
- `aptitude.html` — Aptitude section
- `verbal.html` — Verbal reasoning section
- `gk.html` — General knowledge section
- `contest.html` — Contest section
- `teacher.html` — Teacher profiles
- `courses.html` — Courses section
- `signup.html` — Signup interface

## Getting Started

### Prerequisites

A modern web browser is sufficient to view the website.

### Run Locally

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

For a more convenient development experience, open the folder in Visual Studio Code and use a local server extension such as Live Server.

## Purpose

Learnex brings educational resources together in one place through a simple, multi-page website, making it easier for students to navigate learning topics and find practice materials.
